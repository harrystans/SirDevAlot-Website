**Award:** Staffordshire University Fresher Gamejam Best Game Award

Shards of the Future was created by a two-person team: a 2D artist and myself. I was responsible for the game design and all programming. The gameplay features infinite levels where players must rearrange pots into the correct order. As the game progresses, the pots become increasingly fragmented, raising the challenge. There is a time limit for each level, and at the end, players are awarded 1-3 stars based on their performance.

<p><iframe src="https://www.youtube.com/embed/BjcMkTsQPXE" frameborder="0" allowfullscreen></iframe></p>

## Key Features

- **Procedural Sprite Breaking:** The game can dynamically cut up 2D sprites at runtime, creating new game objects from the fragments.
- **Remaking Pots:** The original positions of the pots are stored, then each is randomly rotated in code. Players must pick up and move the pots to restore the correct arrangement.
