**Project Type:** Indie Work

The Last Harvest is a narrative-driven farming adventure game featuring a custom dialogue tool and branching storylines. This project focuses on deep character interactions, player-driven choices, and a rich, evolving world.

## Features

- Custom dialogue tool for dynamic conversations
- Branching storylines and multiple endings
- Farming, crafting, and exploration mechanics
- Unique characters and relationship systems
